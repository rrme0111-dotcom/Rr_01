# 需求文档 — 粉色Q版转盘选择器

## 项目背景
用户是一个不懂代码的普通用户，想要一个运行在安卓手机上的转盘选择工具。核心场景是玩"烹饪发烧友"游戏时，通过转动转盘来随机决定：玩哪个店、玩几关、能否升级机器、升级几次。

## 目标用户
- 手机用户（安卓为主）
- 不需要安装 App，通过浏览器即可使用
- 偏好可爱、温暖、立体的视觉风格

---

## 功能需求

### F1. 转盘配置管理
| ID | 需求 | 优先级 |
|------|------|--------|
| F1.1 | 用户可以创建新的转盘配置 | P0 |
| F1.2 | 用户可以给转盘命名 | P0 |
| F1.3 | 用户可以编辑已有的转盘配置 | P1 |
| F1.4 | 用户可以删除不需要的转盘配置 | P1 |
| F1.5 | 所有配置保存在手机本地，下次打开仍有 | P0 |

### F2. 多层同心转盘
| ID | 需求 | 优先级 |
|------|------|--------|
| F2.1 | 转盘支持 2~6 个同心圈 | P0 |
| F2.2 | 每圈有独立名称（如"选择餐厅"） | P0 |
| F2.3 | 每圈的选项数量可自由增减（最少2个，最多20个） | P0 |
| F2.4 | 每圈选项文字支持 emoji | P0 |
| F2.5 | 所有圈同时旋转、同时停止 | P0 |
| F2.6 | 一根指针贯穿所有圈，一次转出全部结果 | P0 |

### F3. 转盘样式
| ID | 需求 | 优先级 |
|------|------|--------|
| F3.1 | 提供 3 种可选样式（草莓甜心/樱花物语/甜心蛋糕） | P0 |
| F3.2 | 样式可在创建/编辑时切换 | P0 |
| F3.3 | 默认样式为"草莓甜心" | P1 |

### F4. 旋转与结果
| ID | 需求 | 优先级 |
|------|------|--------|
| F4.1 | 点击旋转按钮触发旋转动画 | P0 |
| F4.2 | 旋转过程有自然的加速-减速效果 | P0 |
| F4.3 | 旋转时有点击/刻度音效 | P1 |
| F4.4 | 停止时有完成提示音效 | P1 |
| F4.5 | 停止后弹出结果弹窗，逐圈展示结果 | P0 |
| F4.6 | 结果弹窗有庆祝动画（撒花/星星） | P1 |
| F4.7 | 支持"再转一次"功能 | P0 |

### F5. 快速模板
| ID | 需求 | 优先级 |
|------|------|--------|
| F5.1 | 提供"烹饪发烧友"一键模板 | P0 |
| F5.2 | 模板预填 4 圈（餐厅/关卡/升级/次数） | P0 |

### F6. 部署与访问
| ID | 需求 | 优先级 |
|------|------|--------|
| F6.1 | 可通过网址在手机浏览器中访问 | P0 |
| F6.2 | 可添加到手机主屏幕（PWA） | P1 |
| F6.3 | 添加到主屏幕后以全屏模式运行（无浏览器地址栏） | P1 |

---

## 非功能需求

| ID | 需求 | 说明 |
|------|------|------|
| NF1 | 移动端优先 | 主要针对手机屏幕（320-428px 宽度）设计 |
| NF2 | 粉色暖色调 | 主色 #FF8FA3，辅色奶油白 #FFF5F5 |
| NF3 | Q版可爱风格 | 圆角、圆润字体、可爱装饰元素 |
| NF4 | 立体感 | 多层次阴影、渐变、光泽效果 |
| NF5 | 离线可用 | PWA Service Worker 缓存关键资源 |
| NF6 | 零依赖 | 纯 HTML/CSS/JS，不依赖任何框架或库 |
| NF7 | 响应快速 | 页面加载 < 2 秒，旋转动画流畅 60fps |

---

## 验收标准
1. 用户能在手机上打开网页，创建转盘，添加圈和选项
2. 转盘能正常旋转并随机停在某个结果上
3. 结果弹窗正确显示每圈的命中选项
4. 关闭页面后重新打开，之前创建的转盘仍在
5. 能添加到手机主屏幕，以全屏 App 形式打开
